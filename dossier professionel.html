🏗️Les balises fondamentales du site

La déclaration DOCTYPE

Tout d'abord, je commence par la balise <!DOCTYPE html>. C'est très important ! Elle dit au navigateur que je vais utiliser du HTML5, la dernière version du HTML.

La balise <html>

Ensuite, j'ouvre la balise <html lang="fr">. L'attribut lang="fr" indique que mon site est en français. C'est utile pour les moteurs de recherche et pour les lecteurs d'écran.

La balise <head>

Je crée une balise <head> qui contient les informations sur ma page. C'est comme les "coulisses" du site - le navigateur ne les affiche pas directement, mais elles sont essentielles.

Les métadonnées - <meta>

À l'intérieur du head, je mets :

  • <meta charset="UTF-8"> : Cela dit au navigateur d'utiliser l'encodage UTF-8, ce qui me permet d'afficher correctement les caractères spéciaux comme les accents en français.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> : C'est crucial ! Cette balise rend mon site responsive, c'est-à-dire qu'il s'adapte à la largeur de l'écran, que ce soit un téléphone, une tablette ou un ordinateur.

Le titre - <title>

Je mets <title>Mafeliki</title>. C'est le texte qui s'affiche dans l'onglet du navigateur et c'est aussi ce que les moteurs de recherche affichent dans les résultats.

Le lien vers le CSS - <link>

Enfin, je mets <link href="mafeliki.css" rel="stylesheet">. C'est très important ! Cette balise relie mon fichier HTML à mon fichier CSS. L'attribut rel="stylesheet" dit au navigateur que le fichier est une feuille de style. Sans cette ligne, mon CSS ne s'appliquerait pas du tout.

Exemple complet du projet :

<!DOCTYPE html>
<html lang="fr">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mafeliki</title>
    <link href="mafeliki.css" rel="stylesheet">
</head>

<body>

    <!--L'en-tête-->
    <header>
        <h2>Mafeliki les fruits et légumes de Mayotte</h2>
    </header>

</body>
</html>

📱La structure globale du site

Organisation générale

Mon site Mafeliki est organisé de manière logique et hiérarchique. Voici comment je structure tout le contenu :

Le header - <header>

Tout d'abord, je place un <header> au début du body. C'est une balise sémantique qui contient :

  • <h2>Mafeliki les fruits et légumes de Mayotte</h2> : Le titre principal du site

Le header a un rôle très important : c'est la première chose que voit le visiteur. Avec mon CSS, j'applique un dégradé vert attractif qui reflète le thème agricole.

La navigation - <nav>

Ensuite, je crée une barre de navigation avec la balise <nav> et une liste <ul> contenant trois liens :

<nav>
    <ul>
        <li><a href="#fruit">Fruit</a></li>
        <li><a href="#legume">Légume</a></li>
        <li><a href="#formulaire">Formulaire</a></li>
    </ul>
</nav>

Les href="#fruit", href="#legume" sont des ancres qui permettent de naviguer vers les sections correspondantes en haut de la page.

Les ancres HTML

Pour que les liens de navigation fonctionnent, je dois ajouter des id aux articles correspondants :

<article id="legume">...</article>
<article id="fruit">...</article>
<section id="formulaire">...</section>

Quand on clique sur le lien "Fruit", le navigateur me déplace automatiquement à la section avec id="fruit". C'est une navigation très fluide et efficace.

Les sections contenant les produits

Le contenu principal est organisé en articles avec deux produits principaux : Légume et Fruit. Chaque article suit la même structure pour la cohérence.

📄La structure des articles

Maintenant que j'ai parlé des balises de base et du CSS, je vais vous expliquer comment j'organise le contenu principal du site.

La section principale - <section>

J'entoure tous les articles dans une balise <section>. C'est une balise sémantique qui regroupe les contenus liés. Cela aide les moteurs de recherche et rend mon code plus lisible.

La section Légume

Je crée un <article> avec l'id "legume" pour pouvoir le cibler depuis la navigation avec le lien <a href="#legume">.

À l'intérieur, je mets :

  • <h2>Légume</h2> : Le titre de la section
  • <p>Un légume est...</p> : Une explication générale
  • <img src="Manioc.jpg" alt="Manioc"> : L'image du produit avec une description alternative
  • <p>5€ le kilo</p> : Le prix
  • <p>Le manioc est...</p> : Une description détaillée

L'importance de l'attribut alt

L'attribut alt="Manioc" est crucial ! Il sert à :

  • Accessibilité : Si un utilisateur utilise un lecteur d'écran, il entendra "Manioc" au lieu d'une image vide
  • SEO : Les moteurs de recherche utilisent le texte alt pour comprendre le contenu de l'image
  • Fallback : Si l'image ne charge pas, le texte alt s'affiche à la place

La section Fruit

Je fais exactement la même structure avec un autre <article> id="fruit". La seule différence, c'est que j'ajoute un attribut width="250" sur l'image pour contrôler sa taille :

<img src="fruit à pain.jpg" alt="Fruit à pain" width="250">

Exemple complet d'un article du projet :

<article id="legume">

    </p>

🔗Les éléments additionnels du site

Le lien Facebook du projet

J'ajoute un lien vers la page Facebook avec cette balise :

<div class="facebook">
    <!--Voici un lien pour se rendre sur la page facebook de Topical Concept Mayotte. Et target est là pour que le lien s'ouvre sur une autre page-->
    <a href="https://www.facebook.com/TropicalConceptMayotte/?locale=fr_FR" target="_blank">

Points importants :

  • J'utilise une <div class="facebook"> pour pouvoir le styliser avec du CSS
  • L'attribut target="_blank" est très important - il ouvre le lien dans un nouvel onglet, ce qui permet au visiteur de rester sur mon site
  • L'URL complète inclut le paramètre locale=fr_FR pour que la page Facebook s'affiche en français

}

J'utilise des classes pour mieux organiser le code. Chaque ligne du formulaire utilise display: flex pour afficher deux champs côte à côte ! Au focus, la bordure devient verte pour montrer que le champ est actif.
