🎯Présentation générale

Bonjour, je m'appelle [Votre nom], et je vous présente mon projet web que j'ai réalisé : Mafeliki - Les fruits et légumes de Mayotte.

J'ai créé un site statique qui met en avant les produits agricoles de Mayotte. C'est un site informatif et commercial qui présente les fruits et légumes locaux, ainsi qu'un annuaire de producteurs.

🏗️Partie 1 : Les balises fondamentales du site

1. La déclaration DOCTYPE

Tout d'abord, je commence par la balise <!DOCTYPE html>. C'est très important ! Elle dit au navigateur que je vais utiliser du HTML5, la dernière version du HTML. C'est la première ligne du fichier, et elle n'a pas besoin de balise fermante.

2. La balise <html>

Ensuite, j'ouvre la balise <html lang="fr">. Cette balise enveloppe tout le contenu de mon site. L'attribut lang="fr" indique que mon site est en français. C'est utile pour les moteurs de recherche et pour les lecteurs d'écran (accessibilité).

3. La balise <head> - La "tête" du site

Je crée une balise <head> qui contient les informations sur ma page. C'est comme les "coulisses" du site - le navigateur ne les affiche pas directement à l'écran, mais elles sont essentielles pour le fonctionnement et le référencement.

4. Les métadonnées - <meta>

À l'intérieur du head, je mets deux balises <meta> très importantes :

  • <meta charset="UTF-8"> : Cela dit au navigateur d'utiliser l'encodage UTF-8, ce qui me permet d'afficher correctement les caractères spéciaux comme les accents en français (é, è, ê, etc.).
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> : C'est crucial ! Cette balise rend mon site responsive, c'est-à-dire qu'il s'adapte à la largeur de l'écran, que ce soit un téléphone, une tablette ou un ordinateur. Sans cette ligne, le site ne s'afficherait pas correctement sur mobile.

5. Le titre - <title>

Je mets <title>Mafeliki</title>. C'est le texte qui s'affiche dans l'onglet du navigateur. C'est aussi ce que les moteurs de recherche (Google) affichent dans les résultats de recherche.

6. Le lien vers le CSS - <link>

Enfin, je mets <link href="mafeliki.css" rel="stylesheet">. C'est très important ! Cette balise relie mon fichier HTML à mon fichier CSS. L'attribut rel="stylesheet" dit au navigateur que le fichier est une feuille de style. Sans cette ligne, mon CSS ne s'appliquerait pas du tout, et le site n'aurait pas de couleur ni de mise en page.

7. La balise <body>

Après le </head>, j'ouvre la balise <body>. C'est ici que je mets tout le contenu visible du site : le header, la navigation, les articles, le formulaire, etc. C'est tout ce que l'utilisateur verra à l'écran.

Exemple complet de la structure de base :

<!DOCTYPE html>
<html lang="fr">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mafeliki</title>
    <link href="mafeliki.css" rel="stylesheet">
</head>

<body>
    <!-- Tout le contenu visible va ici -->
</body>

</html>

📱Partie 2 : La structure du contenu visible

Organisation générale du body

Maintenant que j'ai expliqué la structure de base du fichier, je vais vous montrer comment j'organise tout le contenu visible dans le <body>. Mon site est organisé de manière logique et hiérarchique :

1. Le header - <header>

Tout d'abord, je place un <header> au début du body. C'est une balise sémantique (elle a du sens) qui contient :

  • <h2>Mafeliki les fruits et légumes de Mayotte</h2> : Le titre principal du site

Le header a un rôle très important : c'est la première chose que voit le visiteur. Avec mon CSS, j'applique un dégradé vert attractif qui reflète le thème agricole du projet.

2. La navigation - <nav>

Ensuite, je crée une barre de navigation avec la balise <nav> et une liste <ul> contenant trois liens :

<nav>
    <ul>
        <li><a href="#fruit">Fruit</a></li>
        <li><a href="#legume">Légume</a></li>
        <li><a href="#formulaire">Formulaire</a></li>
    </ul>
</nav>

Les href="#fruit" et href="#legume" sont des ancres qui permettent de naviguer vers les sections correspondantes avec un simple clic. C'est une navigation interne très efficace !

3. Les ancres HTML - Les id

Pour que les liens de navigation fonctionnent, je dois ajouter des id aux éléments correspondants. Par exemple :

<article id="legume">...</article>
<article id="fruit">...</article>
<section id="formulaire">...</section>

Quand on clique sur le lien "Fruit", le navigateur me déplace automatiquement à la section avec id="fruit". C'est comme un raccourci qui saute directement à l'endroit souhaité. Le id doit être unique - on ne peut pas avoir deux éléments avec le même id sur une même page.

Exemple complet de la structure du body :

<body>

    <header>
        <h2>Mafeliki les fruits et légumes de Mayotte</h2>
    </header>

    <nav>
        <ul>
            <li><a href="#fruit">Fruit</a></li>
            <li><a href="#legume">Légume</a></li>
            <li><a href="#formulaire">Formulaire</a></li>
        </ul>
    </nav>

    <section>
        <article id="legume">...</article>
        <article id="fruit">...</article>
    </section>

    <section id="formulaire">...</section>

</body>

📄Partie 3 : Les articles de produits

La structure d'un article - <article>

J'entoure mes produits dans des balises <article>. C'est une balise sémantique très importante qui regroupe une partie de contenu autosuffisant. Elle aide les moteurs de recherche à comprendre que c'est une unité de contenu cohérente.

Exemple complet d'un article :

<article id="legume">

    <h2>Légume</h2>
    <p>
        Un légume est la plante ou la partie d'une plante comestible d'une espèce potagère.
    </p>

    <img src="Manioc.jpg" alt="Manioc">
    <p>5€ le kilo</p>
    
    <p>
        Le manioc est un tubercule populaire dans l'alimentation de plusieurs pays...
    </p>

</article>

Ce que contient chaque article :

  • <h2>Légume</h2> : Le titre du produit
  • <p>Un légume est...</p> : Une définition générale du produit
  • <img src="Manioc.jpg" alt="Manioc"> : L'image du produit
  • <p>5€ le kilo</p> : Le prix du produit
  • <p>Le manioc est...</p> : Une description détaillée et intéressante

L'importance de l'attribut alt sur les images

L'attribut alt="Manioc" est très important ! Il sert à :

  • Accessibilité : Si un utilisateur utilise un lecteur d'écran (pour les malvoyants), il entendra "Manioc" au lieu d'une image vide.
  • SEO (Référencement) : Les moteurs de recherche comme Google utilisent le texte alt pour comprendre le contenu de l'image. Cela aide à mieux referencer mon site.
  • Fallback : Si l'image ne charge pas (mauvaise connexion), le texte alt s'affiche à la place pour que le visiteur comprenne ce qu'il y aurait dû voir.

Contrôler la taille des images

Je peux aussi ajouter des attributs pour contrôler la taille des images. Par exemple :

<img src="fruit à pain.jpg" alt="Fruit à pain" width="250">

L'attribut width="250" force l'image à faire 250 pixels de largeur. Le navigateur ajuste la hauteur automatiquement pour garder les bonnes proportions. Je peux aussi utiliser height si je veux.

🔗Partie 4 : Les éléments additionnels

1. Le lien Facebook

J'ajoute un lien vers la page Facebook du projet. Voici comment je le crée :

<div class="facebook">
    <a href="https://www.facebook.com/TropicalConceptMayotte/?locale=fr_FR" target="_blank">
        Notre page facebook
    </a>
</div>

Points importants :

  • J'utilise une <div class="facebook"> pour pouvoir le styliser avec du CSS
  • L'attribut target="_blank" est crucial - il ouvre le lien dans un nouvel onglet, ce qui permet au visiteur de rester sur mon site
  • L'URL complète inclut le paramètre locale=fr_FR pour que la page Facebook s'affiche en français

2. Le tableau des producteurs

Je crée un tableau pour afficher les producteurs locaux. Voici la structure :

<h2 class="producteurs">
    Tableau de producteurs de fruits et légumes à Mayotte
</h2>
<table>
    <tr>
        <th>Nom</th>
        <th>Prénom</th>
        <th>entreprise</th>
        <th>Type de produit</th>
        <th>village</th>
    </tr>

    <tr>
        <td>Hamada</td>
        <td>Oumar</td>
        <td>Mayana Léguime</td>
        <td>Banane</td>
        <td>Mtsamboro</td>
    </tr>
</table>

Explication des balises :

  • <table> : La balise qui crée le tableau
  • <tr> : Table Row - une rangée horizontale du tableau
  • <th> : Table Header - un en-tête (titre de colonne, dans la première rangée)
  • <td> : Table Data - une cellule de données ordinaire

3. Le formulaire de commande

J'ajoute un formulaire pour que les visiteurs puissent faire des commandes. Voici la vraie structure :

<section id="formulaire">
    <h2 class="formulaire">formulaire</h2>
    <form class="formulaire">
        <div class="ligne">
            <div class="champ">
                <label for="prenom">Prénom(s) :</label>
                <input type="text" name="prenom" id="prenom" required>
            </div>
            <div class="champ">
                <label for="nom">Nom :</label>
                <input type="text" name="nom" id="nom" required>
            </div>
        </div>
        
        <div class="ligne">
            <div class="champ">
                <label for="fruit">Fruit souhaité :</label>
                <select id="fruit" name="fruit">
                    <option value="">-- Choisissez un fruit --</option>
                    <option value="banane">Banane</option>
                    <option value="papaye">Papaye</option>
                </select>
            </div>
            <div class="champ">
                <label for="quantite">Quantité :</label>
                <input type="number" id="quantite" name="quantite" min="1" max="100" value="1">
            </div>
        </div>
        
        <button type="submit" class="envoyer">Envoyer</button>
    </form>
</section>

Explication des éléments du formulaire :

  • <label for="prenom"> : Un libellé (étiquette) associée à un champ. L'attribut for le relie à un input avec le même id
  • <input type="text"> : Un champ texte simple
  • <input type="number"> : Un champ numérique (accepte uniquement les nombres)
  • <select> : Une liste déroulante avec des <option>
  • <button type="submit"> : Le bouton pour envoyer le formulaire
  • required : Un attribut qui rend le champ obligatoire

4. La vidéo YouTube

J'intègre une vidéo YouTube directement dans la page avec une balise <iframe> :

<div class="video">
    <iframe width="560" height="315" 
        src="https://www.youtube.com/embed/JwukBe1bk6I" 
        title="YouTube video player" 
        frameborder="0" 
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
        allowfullscreen>
    </iframe>
</div>

L'<iframe> (inline frame) me permet d'incruster du contenu d'un autre site directement dans ma page. C'est très utile pour les vidéos YouTube, les cartes Google Maps, les documents PDF, etc. L'<iframe> est comme une "fenêtre" vers un autre contenu.

🎨Partie 5 : La feuille de style CSS (mafeliki.css)

Maintenant, je vais vous expliquer comment je crée le fichier mafeliki.css et toutes les règles CSS que j'applique pour rendre mon site beau et fonctionnel.

1. Réinitialisation générale avec le sélecteur universel *

Je commence par réinitialiser tous les styles par défaut du navigateur. Chaque navigateur a ses propres marges et espacements par défaut. Je les supprime tous :

* {
    margin: 0;          /* Supprime les marges externes */
    padding: 0;         /* Supprime les espacements internes */
    box-sizing: border-box;  /* Inclut les bordures et padding dans la taille totale */
    font-family: Arial, sans-serif;  /* Définit la police de base */
}

2. Le style du header

J'ajoute un dégradé vert attractif pour le header :

header {
    background: linear-gradient(135deg, #4CAF50, #2E7D32);
    color: white;
    padding: 20px;
    text-align: center;
    border-bottom: 4px solid #1B5E20;
}

Explications :

  • linear-gradient(135deg, #4CAF50, #2E7D32) : Un dégradé qui va d'un vert clair (#4CAF50) à un vert foncé (#2E7D32) en diagonale (135 degrés)
  • color: white : Le texte est blanc pour bien contraster
  • border-bottom : Ajoute une bordure en bas du header

3. La navigation avec effet au survol

Voici le vrai code CSS de ma navigation :

nav ul {
    list-style: none;      /* Supprime les puces de la liste */
    display: flex;         /* Affiche les éléments en ligne */
    justify-content: center; /* Centre les éléments */
    gap: 40px;            /* Ajoute un espacement entre les liens */
    margin-bottom: 30px;
}

nav ul li a {
    text-decoration: none;  /* Supprime le soulignement des liens */
    color: #2E7D32;        /* Couleur du texte */
    font-weight: bold;     /* Texte gras */
    font-size: 18px;
    position: relative;    /* Pour positionner le pseudo-élément ::after */
}

nav ul li a::after {
    content: "";           /* Crée un élément vide */
    height: 3px;          /* Hauteur du trait */
    width: 0%;            /* Au début, le trait est invisible */
    background: #a2fc07;  /* Couleur du trait */
    position: absolute;   /* Positionné en absolu par rapport au lien */
    left: 0;
    bottom: -3px;
    transition: 0.3s;     /* Animation lisse sur 0.3 secondes */
}

nav ul li a:hover::after {
    width: 100%;          /* Au survol, le trait remplit tout */
}

Cet effet crée un trait vert qui se remplit progressivement quand on survole un lien. C'est très dynamique !

4. Les articles avec effet au survol

Voici comment je stylise les articles :

article {
    width: 80%;
    margin: 30px auto;
    background: #f9f9f9;
    border-radius: 12px;
    padding: 20px;

    transition: transform 0.3s ease;
}

article:hover {
    transform: scale(1.02);  /* L'article grandit légèrement au survol */
}

Pour les images, j'ajoute une animation encore plus spectaculaire :

article img {

article img:hover {

    box-shadow: 0px 10px 20px rgba(0,0,0,0.3);  /* Ajoute une ombre */

6. Le tableau stylisé

Pour le tableau, j'ajoute des styles modernes :

table {
    width: 90%;

    border-collapse: collapse;
    background: white;
    border-radius: 10px;
    overflow: hidden;

    background: #4CAF50;  /* Fond vert pour les en-têtes */

    padding: 12px;
}

table td {
    padding: 12px;
    border-bottom: 1px solid #ddd;
}

table tr:hover {
    background: #f0fff0;  /* Fond léger vert au survol */
    cursor: pointer;
    transition: 0.3s;
}

7. Le formulaire stylisé

Voici comment je stylise le formulaire :

.formulaire {
    width: 80%;
    max-width: 700px;
    margin: 50px auto;
    padding: 25px;
    background: #f9f9f9;
    border-radius: 10px;
    box-shadow: 0px 4px 10px rgba(0,0,0,0.1);
}

.ligne {
    display: flex;         /* Affiche deux champs côte à côte */
    justify-content: space-between;
    gap: 20px;
    margin-bottom: 20px;
}

.champ {
    flex: 1;              /* Chaque champ prend l'espace équitable */
    display: flex;
    flex-direction: column;
}

.champ label {
    font-weight: bold;
    margin-bottom: 6px;
    color: #2E7D32;
}

.champ input,
.champ textarea {
    padding: 10px;
    border: 1px solid #ccc;
    border-radius: 6px;
    font-size: 16px;
    transition: border-color 0.3s;
}

.champ input:focus,
.champ textarea:focus {
    border-color: #4CAF50;  /* La bordure devient verte au focus */
    outline: none;          /* Supprime l'outline bleu par défaut */
}

J'utilise des classes pour mieux organiser le code. Au focus (quand on clique dans un champ), la bordure devient verte pour montrer que le champ est actif.

🌐 Site responsive : J'ai mis la balise <meta name="viewport" content="width=device-width, initial-scale=1.0"> pour que le site s'adapte à tous les appareils (téléphone, tablette, ordinateur).
♿ Accessibilité : J'utilise les bonnes balises sémantiques (<header>, <nav>, <article>, <section>), j'ajoute des attributs alt sur mes images.
🗺️ Navigation fluide : Les liens permettent de naviguer facilement entre les sections avec des ancres (#fruit, #legume, #formulaire).
🎭 Design moderne : Dégradés verts, animations au survol, espacement bien pensé.
📋 Contenu varié : Articles de produits, tableau de producteurs, formulaire de commande, vidéo YouTube, lien Facebook.
🔄 Interactivité : Les images zooment au survol, les liens se soulignent progressivement, le formulaire est facile à utiliser.

🛠️Technologie utilisée

  • HTML5 : Pour la structure sémantique du site, les formulaires, les tableaux, et l'intégration vidéo

  • Images : Intégrées localement (Manioc.jpg, fruit à pain.jpg)
  • Vidéo : Intégrée via YouTube avec une balise iframe
